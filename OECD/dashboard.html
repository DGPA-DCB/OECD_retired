以下參數沒有可自動擷取的開放資料，請依「確認路徑」核對後填寫並把狀態改為「已確認」。修改只會保存在這台電腦的瀏覽器；要讓所有人看到，請按「匯出確認結果」另存 JSON，再到 GitHub 上傳覆蓋 config/manual.json，下次更新後即成為所有人的預設值。

按頁首「更新資料」即可重新抓取所有來源（線上版由 GitHub 自動執行；另每天清晨自動更新一次）。某個來源下載失敗時，會沿用上一次成功的資料並在下表標示；機關原始網址被擋時，會改用 data.gov.tw 平台的轉檔副本。

每年度新開的資料集

退撫基金管理局每年度會新開一個資料集。更新時會自動到 data.gov.tw 搜尋並併入新年度，不需手動加入；下表為最近一次搜尋結果。若自動搜尋失敗，可用「查詢連結」找到編號，再用「手動新增」加入設定檔。
